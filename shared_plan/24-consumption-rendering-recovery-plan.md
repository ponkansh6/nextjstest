# 名目・実質消費の民間最終消費支出→CTI接続表示 改修プラン

作成日: 2026-09-11
更新日: 2026-09-11
状態: 訂正後実装、型検査、スケーリング、境界、2025年表示、tooltip数値一致の再検証まで完了。

## 目的

名目・実質の消費グラフを、2017年Q4までは国民経済計算の民間最終消費支出、2018年Q1以降はCTI費目別消費支出として接続表示する。同一四半期に両系列を重ねず、2018年以降に国民経済計算由来の民間最終消費支出系列を表示しない。独立した折れ線として併記する案は撤回する。

本書でいう「民間最終消費支出」は総GDPではない。国民経済計算を出所とするGDP構成項目の一つである。ファイル名・内部関数名・既存コメントに `GDP` が残る場合も、統計概念やユーザー向け表示名まで「GDP」と読み替えない。

## 要件訂正と既存実装の扱い

以前のPlan24は「CTI積み上げ棒 + GDP独立線」をあるべき表示としていたが、ユーザー確認により誤りと判明した。正しい表示契約は次のとおり。

| 期間           | 国民経済計算の民間最終消費支出 | CTI費目別消費支出            |
| -------------- | ------------------------------ | ---------------------------- |
| 2005Q1〜2017Q4 | 単独の棒として表示             | 表示しない                   |
| 2018Q1以降     | 表示しない                     | 費目別の積み上げ棒として表示 |

- 境界は `2017Q4 → 2018Q1` とする。
- 2017年にCTI入力値が存在しても、接続表示では使用しない。
- 2018年以降に国民経済計算の民間最終消費支出値が存在しても、消費チャート・tooltip・凡例へ出さない。表・CSVなど検証用データ面へ残すかは表示面ごとに仕様を明記し、「表示用データ」という曖昧な一括表現を使わない。
- 国民経済計算の民間最終消費支出とCTIを同一四半期に積み上げず、二重計上による段差を作らない。
- 民間最終消費支出の線を描画しない。旧契約・凡例・テスト・OpenSpec記述は訂正後契約へ整理する。
- 「接続」は統計的な連結計算ではなく、表示期間を境界で切り替えて一つの時系列グラフ上に連続配置することを意味する。
- 2017Q4と2018Q1の水準差を埋める補間、係数合わせ、境界値の複製は行わない。

既に記録された線の実装、E2E成功、キャプチャ確認は旧要件に対する結果であり、訂正後要件の達成根拠として使用しない。完了チェックは訂正後の実装と再検証に基づいて付け直す。

## Plan23・旧Plan24に対する反省

1. 表・CSV・tooltipの数値一致を確認しても、GDPとCTIの表示期間や重ね方が正しいとは限らない。数値経路と描画契約を分けて確認する。
2. 「比較線」という文言から描画方式を決め、利用者が意図する時系列の引継ぎを確認できていなかった。今回確定した境界と表示対象を受入条件へ直接記載する。
3. 2025年だけの確認では、2017Q4→2018Q1の切替や重複表示を検出できない。全期間と境界拡大表示を必須にする。
4. テスト成功数だけで完了としない。今回の不正なGDP線、2018年以降のGDP表示、GDP+CTIの積み上げがそれぞれ失敗になるテストを持つ。

## なぜ今回のミスが起きたか

1. **データの出所と統計概念を混同した。** 国民経済計算から取得した系列であることを理由に、民間最終消費支出を「GDP」と短縮した。出所がGDP統計であることと、表示対象が総GDPであることは別である。
2. **内部名を画面仕様へ持ち込んだ。** loader、定数、テストにある `Gdp` / `GDP` という実装上の呼称を、そのまま利用者向け系列名と描画要件として扱った。
3. **「comparison line」という過去文言から描画方式を推測した。** 系列の統計的意味、表示期間、境界での引継ぎを先に確定せず、折れ線という形を仕様へ追加した。
4. **表示面を区別しなかった。** チャート、tooltip、凡例、表、CSV、公開projectionを「表示」と一括りにしたため、「2018年以降は表示しない」と「2025年値を表・CSVで検証する」が文書内で衝突した。
5. **正常値の存在を正常表示とみなした。** 2025年の値・係数・表・CSVが正しくても、2017Q4→2018Q1の系列切替、tooltip合計、凡例の意味は保証されない。
6. **キャプチャの確認項目が粗かった。** 棒の高さと重複には注目したが、2017年以前のtooltipが「民間最終消費支出 85.24」に対して「合計 0.00」となる矛盾を完了前に拾えなかった。

この反省から、今後は「出所」「統計概念」「公開表示名」「描画形式」「有効期間」「各表示面」を別々の欄で定義し、相互対応を確認してから実装・完了判定を行う。

## データとスケーリングの前提

国民経済計算の民間最終消費支出（名目・実質）は、それぞれの公式四半期原値に独立した表示係数を適用し、2025Q1〜Q4の平均を100とする。名目と実質で係数を共有しない。CTIの採用基準・値は既存の公式系列を維持し、境界を合わせるための再スケーリングを行わない。

### 2025年平均=100の確認手順

名目と実質を別々に、保存済み公式四半期CSVから独立再計算する。

1. 名目は `data/source/cti_support_nominal_quarterly2025.csv`、実質は `data/source/cti_support_real_quarterly2025.csv` を読む。
2. 各CSVから `2025-Q1`〜`2025-Q4` の有限かつ正の原値を4件だけ抽出する。欠損、重複、四半期不足があれば検証失敗とする。
3. 各系列について原値平均 `M = (Q1 + Q2 + Q3 + Q4) / 4` を計算する。
4. 表示係数 `F = 100 / M` を計算する。実装が保持する名目・実質それぞれの係数と、丸め前の許容誤差内で一致することを確認する。
5. 各期の比較指数 `Ii = Qi × F` を算出し、丸め前の `(I1 + I2 + I3 + I4) / 4` が100になることを確認する。
6. 公開projectionの各2025四半期値が、上記の独立計算値を小数2桁へ丸めた結果と一致することを確認する。
7. 名目係数を実質へ、実質係数を名目へ適用するとテストが失敗することを確認し、係数の独立性を担保する。
8. チャート、tooltip、表、CSVが同じ公開比較値を参照することを2025Q1〜Q4すべてで照合する。ただし2018年以降のGDPは消費チャート上に表示しないため、チャート・tooltipではGDPが存在しないことを確認し、GDP比較値そのものはデータ経路の回帰検証で照合する。

期待値をテスト対象の生成関数から取得してはならない。CSV原値と記録された正規化情報からテスト側で再計算し、計算式・入力4値・係数・丸め前後の結果を検証ログへ残す。
