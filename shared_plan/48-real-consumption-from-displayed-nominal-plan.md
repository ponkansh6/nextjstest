# 表示中の名目消費支出をCPIで実質化する計画

> 状態: 2017年以降の比較測定と方式決定は完了。選定方式Eの実装・仕様同期は進行中。2005–2016年への適用、カバレッジ、公開範囲などは未確定。実装時に本計画と `openspec/specs/nextjstest/spec.md` を同期する。

## 目的と採用範囲

「消費支出実質」は「消費支出名目」で現在表示している同じ対象・期間・費目を基準に実質化する。名目系列の期間ごとの採用値とcanonical 10費目は [Plan47](47-nominal-consumption-series-merge-plan.md) に従う。2005Q1–2016Q4はPlan39の世帯構成補正済み接続推計、2017Q1以降は公式調整四半期系列を使用する。実質化によって別の消費系列、別の期間、別の集計対象へ切り替えない。

現行「消費支出実質」で使う「民間最終消費支出」は退役させる。名目表示の各期・各費目の値を出発点にCPIで価格調整する。2017年以降の方式比較に基づき方式Eを決定した。2005–2016年は名目支出の独立した費目別値がないため、歴史期への適用妥当性と利用可能カバレッジは別に確認する。

## 決定済み計算定義と単位確認

初回の単位照合では、現行名目表示入力は円額ではなく「2025年の消費支出平均月額=100」とする指数単位だった。従って円建て実質額として説明してはならない。方式Eは2025年基準の月次CPIを四半期内で算術平均し、名目表示指数とCPIをともに基準100として比率化する。費目 `c`・四半期 `q` について:

`Real_q,c = Nominal_q,c × 100 / mean(CPI_m,c for m in q)`

`Real_q,total = Nominal_q,total × 100 / mean(CPI_m,持家の帰属家賃を除く総合 for m in q)`

費目 `c` のCPIは食料、住居、光熱・水道、家具・家事用品、被服及び履物、保健医療、交通・通信、教育、教養娯楽の9費目では同名大分類を使い、住居は「持家の帰属家賃を除く住居」とする。CTI「その他」は符号付き残差で保持し、「持家の帰属家賃を除く総合」を一般proxyとして使う。これはCPI「諸雑費」への分類置換ではない。CPIは [Plan18](18-cpi-2025-fixed-weight-plan.md) の検証済み2025年基準接続指数を使う。公表値は1桁丸めで2025年の月次総合平均は100.008333だったため、主式は定義上の基準100を使う。実測年平均100.008333を使う方式は感度分析として分けて記録する。基準年と表示単位を実質値のmetadataおよび情報文に記録する。

この定義は名目支出指数を2025年基準のCPIで価格調整した実質指数であり、円建て額ではない。総合は名目総合を独立変換し、10費目の実質和も別定義で保持する。実装時にrow value、measurement `unit`、基準年、集計方法、chart/table/CSVの表示単位を再確認する。四半期表示値を固定した後、四半期内の月次CPIを算術平均して適用する。

## 2017年以降の方式検証（測定完了・方式決定）

### 測定結果の追記欄

### 同じ基本CTI系列の公式実質との比較

2017Q1–2026Q2の38四半期について、同一の基本CTI月次名目を月次総合CPIで実質化してから3か月平均し、公式基本CTI月次実質の3か月平均と比較した。

この公式基本CTI実質比較表は方式Aの参照比較であり、方式Eを公式実質と比較した結果ではない。公式実質は比較参照系列であって同一概念の正解値とは限らず、一致しないことを方式の合否条件にはしない。入力CSVの1桁丸めにより、2025年平均100.008333を使った感度と基準100では水準がわずかに異なる。

方式A–Eの比較測定を行い、名目・実質総合および10費目、実質/名目比、前年比推移、最大差と影響を比較した。方式Eを実装方式として選定したが、名称対応・proxyは分類同一性を意味しない。住居費の帰属家賃込み/除外の差も数値上一致したものとはしない。方式Aの公式基本実質参照比較は上表に限定され、方式Eとの比較は未実施である。

この検証は2017年以降の公式調整名目値を使った方式感度の評価であり、実質消費の独立した正解値との誤差検証ではない。比較した方式の値が似ていることだけで歴史的な実質値の妥当性を証明しない。方式Eは実装方式として決定済みだが、歴史期の適用限界と入力カバレッジは未確認である。

## 集計と系列の整合

- 表示用の名目四半期値を先に確定し、その後CPI変換する。名目値の採用期間、Plan39/公式境界、費目、四半期値を実質化処理で再構成しない。
- 月次名目値が変換元として利用できる期間は、四半期変換後の名目値を実質化する結果と、月次の名目値/CPIを先に計算して四半期集計する結果を感度分析する。集計順序の差を報告し、公開表示は四半期表示名目を先に固定した方式に揃える。
- 2017Q1–2026Q2の基本CTI名目に対する集計順序感度は、方式Eの総合でMAE 0.005830pt、最大絶対差0.028389ptだった。比較対象系列、Other残差生成規則はscriptとともに記録し、公開実質値には四半期表示名目を先に変換する方式を使う。
- 公式名目「その他の消費支出」は総合−9費目の残差である。各費目を別々のCPIで実質化すると、実質10費目の合計は公式総合名目を総合CPIで変換した値と一般には一致しない。負の残差、異なる価格指数による非加法性、CPI対象と消費支出対象の分類不一致を隠さず、実質総合の定義と画面上の合計の扱いを決める。
- 一律CPI方式で名目側10費目の和が総合と一致している場合も、丸めや入力定義差の許容範囲を明記する。費目別方式では「実質総合を実質費目の和とする」のか「総合CPIで別計算する」のかを測定結果に基づいて一つ選び、両者を同じ概念として併記しない。
- CPI費目系列が未公表、欠測、非有限、対応カテゴリ不明、または当該四半期を構成できない場合、値を0・前値・別指数で埋めない。実質値を`null`とし、status/reasonを保持する。
- CPI指数が非正値または妥当性検査に失敗した場合は除算せず、機械可読reasonを示す。
- CPIは名目系列に合わせて四半期平均を基本とする。名目四半期に対して期末月CPIを使う別方式は、根拠を示した感度分析に限り、採用する場合は明示する。

## 2017境界、季節性、成長率

2016Q4/2017Q1を含む境界検証では、名目側の切替と価格調整の寄与を分けて表にする。名目値、CPI係数、実質値の差を追い、境界の不連続が名目source切替・季節形状・価格指数のどれに関連するか記録する。境界差を実質化処理で平滑化・再基準化しない。

欠測のある四半期を補間して境界評価に含めない。年・四半期の範囲、完全年のみの集計、季節性の有無を明記する。前期比や前年比を示す場合、実質水準から同じ四半期粒度で算出し、前年同期が欠ける場合は未定義とする。2016/2017境界をまたぐ前年比は、source切替を含む比較として識別し、通常の同一source内比較と混同しない。

## 民間最終系列の退役範囲

実装時に、実質表示の系列registry/key、値の取得経路とjoin、四半期集約、chart stack/凡例、tooltip、表、CSV、説明文、実質データモデル、テストfixtureおよび参照仕様をたどり、「民間最終消費支出」が現行実質表示へ出る経路を退役させる。名目表示と同じcanonical 10費目・期間・順序に実質値を対応させ、古い民間最終系列がグラフ・表・CSV・tooltipや内部の実質公開rowへ混入しないようにする。キー削除が保存済み利用者データ/API互換性へ影響する箇所は実装前に確認し、単なる内部source名と公開series keyを区別する。

Plan39等の名目年次アンカー、CTI入力、公式名目系列、共用artifactは他の用途にも使われる。実質経路の退役を理由に、名目推計や共有入力を削除しない。不要データと共有データの境界を実装差分で確認する。

1. 現行の名目/実質で公開するseries key・期間・row value・unit・base year・frequency・aggregation・sourceを一覧化し、画面、表、CSVおよびloader経路を照合する。名目表示が「2025年の消費支出平均月額=100」の指数であることを実装とmetadataで再確認する。
2. 初回の集計順序比較および公式実質比較scriptとinput snapshotを再現可能な形で参照し、欠測規則とOther残差生成規則を含む根拠を確認する。
3. 完了済みの方式比較を [`48-cpi-display-impact-measurements.md`](48-cpi-display-impact-measurements.md) と再現scriptで参照し、分類対応・公式基本実質との概念差を明示する。
4. 決定済み方式E（実質総合の独立変換、費目和、符号付きOther残差）を実装し、2017年以降の測定から2005–2016年へ外挿できない範囲を記録する。
5. 既存民間最終実質系列の読込・変換・表示経路を外し、確定したCPI変換を名目公開値に適用する。各値にsource、unit、base year、aggregation、CPI識別情報、status/reasonを付ける。欠測時はfail closedを維持する。
6. graph、凡例、tooltip、table、CSVをcanonicalな名目/実質費目に揃え、実質情報文を「2025年基準実質指数」等の実際の方式・単位・概念に合わせて更新する。
7. 実装と並行して仕様書のData Sources / Data Flow / Data Model / Component Tree / Requirementsを更新し、要件をWHEN/THENシナリオで記述する。

## 仕様同期で反映する内容

- **Data Sources**: Plan47で選んだ名目四半期値、Plan18の2025年基準CPI系列、費目対応表（採用時）、snapshot/metadata。
- **Data Flow**: 名目四半期canonical選択 → 対象四半期CPI集計 → 実質変換 → 共通公開projection → chart/table/tooltip/CSV。
- **Data Model**: 実質費目のseries key/descriptorとmeasurementの`unit`、基準年、source、aggregation、status/reason、CPI/名目provenance。実質総合が費目合算か独立変換かを明記。
- **Component Tree**: 民間最終系列を使う旧実質経路を除き、名目値から変換した実質値を全表示面で共有する経路。
- **Requirements**: 2005–2016変換、2017以降公式名目の同一変換、欠測、残差/総合、2016Q4/2017Q1境界、全表示面parity、旧系列の非公開をWHEN/THENで記載。

## 受入条件

- **WHEN** 名目表示のseries keyと測定値を実質表示へ写す、**THEN** 対象期間・canonical費目の対応を維持し、「民間最終消費支出」は実質公開系列に含めない。
- **WHEN** 実質値を生成する、**THEN** 単位が2025年消費支出平均月額=100の名目指数と整合し、基準100の式、CPI系列、変換元名目値をprovenanceで追跡できる。
- **WHEN** CPI方式を確定する、**THEN** 2017Q1以降の影響比較、帰属家賃/費目別方式比較、公式基本実質との比較結果と限界を記録し、公式実質との一致を合否条件にしない。
- **WHEN** 公開実質値を集計する、**THEN** 表示四半期名目を先に固定してからCPI変換し、月次先変換との差は感度結果として記録する。
- **WHEN** 2016Q4/2017Q1境界、季節または前年比を確認する、**THEN** source切替を識別し、欠測を補間せず、境界を平滑化しない。
- **WHEN** 実質10費目と総合を表示する、**THEN** 加法整合条件、丸め許容、負値、CPI対象不一致の扱いが定義され、積上げと合計の矛盾を隠さない。
- **WHEN** chart、legend、tooltip、table、CSVで同じ値を見る、**THEN** 実質値、単位、provenanceが一致し、退役系列の値/keyが公開されない。
- **WHEN** 実装と仕様同期を完了する、**THEN** 仕様書のData Sources / Data Flow / Data Model / Component Tree / Requirementsが実装と一致し、関連要件をWHEN/THENで記述する。
