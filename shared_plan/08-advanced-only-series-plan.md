# 3種比較に「上級者向け」隠し系列（民間最終消費支出・2017年以降）を追加する

> **[状態]** 本ドキュメントはプランのみ。実装は未着手。

## Context

3種比較（`new-graph`）は現在、消費支出を2つの独立した系列で並置している（プラン07で決定）。

| 系列                       | 期間         | ソース                                            |
| -------------------------- | ------------ | ------------------------------------------------- |
| `民間最終消費支出（参考）` | 2005〜2017年 | 四半期別GDP統計「民間最終消費支出（名目原系列）」 |
| `CTI消費支出（参考）`      | 2018年〜     | 分布調整済み原数値CTI「消費支出（名目）」         |

この構成では **同一期間を2つの物差しで測ったらどう違うか** を読者が確認できない。
プラン07の検証2・検証4で示した「同じ2019年増税がCTIでは2.8倍に描かれる」という事実は、
本来チャート上で直接見えると説得力が高い。

一方で、GDP系列を2018年以降も常時描くと **グラフが5本になり、かつ2本の消費系列が
「どちらが正しいのか」という誤読を一般読者に強いる**。プラン07で2系列分離を選んだ判断
（物差しの違いを隠さないが、比較可能であるかのように見せない）とも整合しない。

そこで、**GDPベースの民間最終消費支出を2017年以降まで延長した系列を「通常は非表示かつ
凡例にも出さない」隠し系列として追加し、方法論を理解している読者だけが解除できるようにする**。

| 項目               | 決定                                                                              |
| ------------------ | --------------------------------------------------------------------------------- |
| 解除UI             | **案B + 案A の併用**: ⓘ（データソース）パネル内のトグル ＋ `?adv=1` URLパラメータ |
| 新系列のデータ範囲 | **2017年〜最新**（既存の民間最終系列の終端2017年と1年重複させ、線を連続させる）   |
| 既定状態           | 非表示。**凡例チップも出さない**                                                  |
| 解除時             | 系列を描画し、**凡例チップも同時に出す**（凡例に無い線は解釈不能なため）          |

## 検討したUI案と採否

| 案                                                                      | 採否     | 評価                                                                                                                                             |
| ----------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **A. URLクエリでのアンロック（`?adv=1`）**                              | **採用** | 一般ユーザーへのUIコストがゼロ。状態がリンクで共有・ブックマークできる。ただし単体では発見不可能なので入口が要る                                 |
| **B. ⓘパネル内の「上級者向け表示」トグル**                              | **採用** | 方法論を気にする読者だけが開く場所にスイッチを置ける。「物差しが異なる」注記とスイッチが同居するので誤読リスクが最小。偶発的なONもほぼ起きない   |
| C. グラフ下の折りたたみ（`<details>`）                                  | 却下     | 段階的開示として正統でa11yも堅いが、閉じていても見出しが常に見える。「通常は隠したい」要件に対して目立ちすぎ、一般読者が開いて誤読する余地が残る |
| D. 隠しジェスチャ（タイトル長押し / Shift+凡例クリック / キーコマンド） | 却下     | 発見不能、タッチ端末で再現しづらい、誤操作しやすい、E2Eテストが困難。既知のアンチパターン                                                        |

**B+A を併用する理由**: B が「入口（発見性）」を、A が「共有と再現性」を担当する。
どちらか一方では、知っている人だけが使えるが共有できない（B単独）か、
共有はできるが誰も辿り着けない（A単独）になる。

## 現状調査で確認した事実

### データは既に存在する（追加取得不要）

`data/source/cti_support_nominal.csv`（四半期別GDP速報・名目原系列）は **1994Q1〜2026Q1** をカバーする。
`server/lib/data-loader/cpi.ts` の `loadCtiDataInternal` は、2017年以降のCTI行にも
`民間最終消費支出（名目）` を四半期ラベル経由で join 済み（`cpi.ts:113-115`）。

実測（`loadCtiDataInternal` / `loadTotalEarningData` を直接叩いて確認）:

```
2020年のCTI行: 12件, 民間最終（生値）= 74875.4 [10億円], CTI消費支出（名目）= 102.4817 [指数]
民間最終（生値）が存在する最終月: 2026年3月
```

つまり **2017年以降の民間最終は生データとして揃っており、CTI系列とほぼ同じ終端まで描ける**。

### スケールは既に揃っている（再基準化は不要）

- `calculateSupportScale(ctiData, "民間最終消費支出（名目）")`（`chartUtils.ts:10`）が
  GDP生値を **2020年平均=100** の空間へ落としてから `minkanRawMap` に入れている（`earnings.ts:73`）
- `minkanFactor = ctiFactor`（`earnings.ts:189`）で、CTI側と共通のスケール係数を適用している
- 実測の継ぎ目: **2017年12月 民間最終 = 101.34 / 2018年1月 CTI = 101.06** → 同一スケール空間で連続

したがって延長系列は追加の指数化を必要とせず、既存2系列とそのまま重ねられる。

### 現状の「隠す」実装コスト

- 凡例は `LINE_CONFIGS`（`src/lib/chartConstants.ts:184-189`）を素直に map しているだけ（`NewGraph.tsx:58`）
- 線も同じ配列を map し、`hiddenKeys` に含まれる場合は **`<Line>` 自体を描画しない**（`NewGraph.tsx:108-121`）

→ 「凡例から隠す」は `LINE_CONFIGS` にフラグを足してフィルタするだけ。
→ 非表示時に `<Line>` を出さない現行方式のため、**Y軸ドメイン・ツールチップ・カーソルに漏れない**（この方式を維持する）。

### URL状態の下地

`src/hooks/useUrlState.ts` が `from` / `to` / `hidden` を
`window.history.replaceState` で同期している（`router.replace` によるスクロール位置リセットを避けるため）。
`adv` パラメータもこの仕組みに相乗りする。

## 仕様

### 系列定義

| 項目       | 値                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| データキー | `民間最終消費支出（参考・延長）`                                                                         |
| 表示ラベル | `民間最終消費(延長・参考)`                                                                               |
| 期間       | 2017年1月〜生データ終端（2026年3月）。2016年12月以前は `null`                                            |
| スケール   | 既存の民間最終系列と同一（`minkanFactor`）。2020年平均=100空間                                           |
| 線の見た目 | 破線（`strokeDasharray`）＋既存の民間最終色（`#38bdf8`）より彩度を落とした色。主系列に視覚的に従属させる |

2017年で既存系列と1年重複させることで、解除時に2005年からの民間最終ラインが
途切れずCTI期間へ延びて見える。

### 表示挙動

| 状態                             | 凡例チップ         | 線         | ツールチップ | データテーブル                       |
| -------------------------------- | ------------------ | ---------- | ------------ | ------------------------------------ |
| 既定（`showAdvanced === false`） | 出さない           | 描画しない | 出ない       | 出さない                             |
| 解除（`showAdvanced === true`）  | 出す（トグル可能） | 描画する   | 出る         | 表示する（要検討、下記「未決事項」） |

### 解除方法

1. **ⓘパネル内トグル**: 3種比較の ⓘ を開く → パネル末尾に
   `上級者向け表示: 民間最終消費支出を2017年以降も表示` のチェックボックス。
   直下に注記「CTIとは物差しが異なるため、2つの消費系列を直接比較することはできません。
   統計間の描かれ方の差を確認するための参考表示です。」
2. **URL**: `?adv=1` が付いていれば初期状態で解除。トグル操作は URL に `adv=1` を書き戻す（共有可能）。
   OFF に戻したらパラメータを削除する。

初期値の優先順位: URL `adv` → localStorage → `false`。

### アクセシビリティ

- トグルはネイティブ `<input type="checkbox">` + `<label>`。`ChartInfoButton` は
  既にフォーカストラップ実装済み（`ChartInfoButton.tsx:66-`）なのでフォーカス可能要素の追加と相性が良い
- 解除時は凡例チップが増えるため、`aria-pressed` を持つ既存の凡例ボタン実装（`NewGraph.tsx:63`）をそのまま使う

## 実装手順

### 1. データ層 — `server/lib/data-loader/earnings.ts`

- `buildConsumptionMaps`（`:56-89`）の `minkanRawMap` から `year <= 2017` 制限を外し、全期間を格納する。
  - trailing MA は後方エントリの追加が過去の値に影響しないため、**既存2005〜2017系列の値は変化しない**。
    これは回帰テスト（手順6）で担保する。
- 結果ループ（`:271-283`）に新系列を追加:
  ```ts
  item["民間最終消費支出（参考・延長）"] =
    parsedYear >= 2017 && maMinkan > 0 ? maMinkan * minkanFactor : null;
  ```
- 既存の `民間最終消費支出（参考）`（`<= 2017`）、`CTI消費支出（参考）`（`>= 2018`）、
  互換用 `消費支出（参考）` は一切変更しない。

### 2. 型 — `src/types/data.ts`

`CpiData`（`:7-8` 付近）に `"民間最終消費支出（参考・延長）"?: number | null;` を追加。

### 3. ビューモデル — `src/app/page.tsx`

`earningsKeys`（`:71-72` 付近）に新キーを追加。

### 4. 系列設定 — `src/lib/chartConstants.ts`

- `LineConfig`（`:178-182`）に `advanced?: boolean` と `strokeDasharray?: string` を追加
- `LINE_CONFIGS`（`:184-189`）に新エントリを追加（`advanced: true`）
- **色の変更・追加は `feedback_chart_color_change_procedure` の手順に従う**（配列位置ミス防止のため
  `preview` で確認してから3ファイルを更新する）

### 5. 描画 — `src/app/components/NewGraph.tsx`

- props に `showAdvanced: boolean` を追加
- 凡例の map（`:58`）と線の map（`:108`）の両方を
  `LINE_CONFIGS.filter((c) => !c.advanced || showAdvanced)` に差し替える
- `strokeDasharray` を `<Line>` に渡す
- 非表示系列は `<Line>` 自体を描画しない現行方式を維持する（Y軸・ツールチップへの漏れ防止）

### 6. 状態管理 — `src/hooks/useUrlState.ts` / `src/app/components/CpiChart.tsx`

- `useUrlState` に `adv` の読み取りと `updateUrl` での書き込みを追加（`hidden` と同じ扱い、
  `window.history.replaceState` 方式を踏襲してスクロール位置を壊さない）
- `CpiChart` に `showAdvanced` state を追加（初期値: URL → localStorage → false）。
  変更時に localStorage と URL の両方へ同期し、`NewGraph` と ⓘ へ渡す

### 7. ⓘパネル — `src/app/components/ChartInfoContentRenderer.tsx` / `src/lib/chartInfoContent.ts`

- `ChartInfoContentRenderer` に `footer?: ReactNode`（または `children`）を追加し、
  静的コンテンツの後ろにインタラクティブ要素を差し込めるようにする
- `NewGraph` から3種比較のⓘにトグルを渡す
- `chartInfoContent.ts` の `new-graph`（`:153-179`）の「表示している系列」に
  延長系列の説明を1項目追加する（期間・ソース・直接比較不可の注記）

### 8. データテーブル — `src/app/components/DataTablesSection.tsx`

新キーがデータテーブルに自動的に出るかを確認し、既定状態では出ないようにする
（→「未決事項」参照）。
