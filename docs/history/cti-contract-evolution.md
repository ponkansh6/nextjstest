implementation notes/artifacts and the current domain names. Existing evidence,
snapshots, and requirement anchors keep their original identifiers. Current
runtime behavior is specified in
[`openspec/specs/nextjstest/spec.md`](../../openspec/specs/nextjstest/spec.md).

## Writer parity and rollback verification coverage

`tests/scripts/plan39/rollback.test.mjs` covers mixed canonical/legacy annual
schema values, unknown schema rejection, and artifact hash/revision mismatches
through the exported rollback loader-hash verifier. The verifier normalizes only
the two explicitly supported annual schema values to their shared family while
retaining exact SHA, revision, path, statistical-code, and value-type checks.
