# Plan49 実装前ゲート検証スクリプト

## 概要

`scripts/plan49/pre-impl-gate.mjs` は、Plan49（NewGraphの消費総合系列を月次12MAで表示する計画）の要件に基づき、データソースの整合性、歴史的推計値の再現性、2013年12か月完全性、2017年以降の公式月次系列（`000040499028`）の欠測状況、および公式四半期値（`000040499087`）との対応を確認するための検証スクリプトです。

## 実行方法

プロジェクトのルートディレクトリで以下のコマンドを実行してください。

```bash
node scripts/plan49/pre-impl-gate.mjs
```

## 検証項目

1. **2005–2016年の歴史的推計と四半期整合性**:
   - Plan39の年次アンカー `A[y]` と二人以上世帯raw月次総合指数 `000040499070` から算出した月次配分 `m[y,m]` の算術平均が、既存Plan39の四半期総合値 `Q[y,q]` と完全に一致することを確認。
2. **2013年の12か月完全性と2014-01窓の確認**:
   - 2013年1月～12月のrawデータがすべて揃っており、2014-01の12MA窓（2013-02..2014-01）を満たすことを確認。
3. **2017年以降の公式月次系列（`000040499028`）の確認**:
   - 2017年01月～の欠測月一覧および2025年12か月の完全性を確認（B計算可否）。
4. **公式月次3か月平均 vs 公式四半期値（`000040499087`）の比較**:
   - 対応期間のデータ存在確認と、公表桁に基づく丸め許容幅（±0.1）の定義に基づく比較評価。
